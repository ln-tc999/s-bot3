## 1 — What it is

Pin this one.

```
An index fund is two things: a set of rules, and a set of numbers that move.

Almost every product blurs them — so whoever can move the numbers can usually rewrite the rules too.

s-bot3 keeps them apart, and the contract is what keeps them apart.

@BOTChain_ai
```

## 2 — The lock

```
Publish an index and you can freeze its methodology forever.

One transaction. After it the rules can never be rewritten — not by an admin, not by us, not by you.

There is no unlock function, and nobody who could add one.

@BOTChain_ai
```

## 3 — The agent

The most distinctive thing the project does. Pair it with a screenshot of the
Rebalancer card showing the `Scoped to: setWeights` row.

```
Hand a rebalancing agent the weight key and it can set weights. That is all it can do.

Not the methodology. Not ownership. It cannot even delegate onward.

And it can still rebalance after the methodology is frozen — the lock covers the rules, not the numbers.

@BOTChain_ai
```

## 4 — How it settles

```
Subscribing to an index does not pay in dollars. It delivers the basket itself — every constituent, in the weights the index publishes at that moment.

Redeeming returns a pro rata slice of what the vault actually holds.

So it can never owe back more than it has.

@BOTChain_ai
```

## 5 — Drift, and what is readable

```
When an agent rebalances, the holdings drift from the published weights. That gap is a number anyone can read.

It closes as new subscriptions arrive at the new weights — no oracle, no DEX, no trade.

Every field comes from one contract read.

@BOTChain_ai
```

## Two things not to claim

**Never imply a return.** There is no price exposure here: each vault's unit
prices are declared at deployment and immutable, and the only thing that moves
NAV is the fee. "Earn yield", or any figure that reads as performance, would be
untrue — and that is an expensive kind of untrue in a financial context.

**No mainnet addresses until there are any.** Only testnet `968` is live.
